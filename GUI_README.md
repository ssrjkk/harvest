# HARVEST GUI - Веб-интерфейс

**Автор:** [ssrjkk](https://t.me/ssrjkk_bot) · © 2026 ssrjkk

Современный веб-интерфейс для управления фармером через браузер.

## Запуск

### Через меню
1. Запустите `python main.py`
2. Выберите тестнет
3. Нажмите `G` в главном меню
4. Откройте браузер: http://127.0.0.1:8080

### Напрямую
```bash
python -c "from core.web_gui import start_gui; start_gui()"
```

## Возможности

### Кнопки управления
- **⚙️ Инициализация** - загрузка конфига, БД, сети
- **💰 Создать кошельки** - генерация новых кошельков
- **🚰 Запросить кран** - пополнение балансов через faucet
- **▶️ Старт фарм** - запуск циклов фарма
- **⏹️ Стоп фарм** - остановка фарма

### Real-time мониторинг
- Статус фарма (запущен/остановлен)
- Количество кошельков
- Общее количество действий
- Процент успеха
- Логи в реальном времени через WebSocket

### Статистика
- Топ-10 кошельков по активности
- История циклов фарма
- Детальная статистика по всем операциям

## Технологии

- **Backend**: FastAPI (Python)
- **Frontend**: HTML5 + CSS3 + Vanilla JavaScript
- **Real-time**: WebSocket для мгновенных обновлений
- **Дизайн**: Современный градиентный UI, адаптивный

## API Endpoints

- `GET /api/status` - текущий статус
- `POST /api/init` - инициализация системы
- `POST /api/wallets/create?count=N` - создание N кошельков
- `POST /api/faucet/request` - запрос крана
- `POST /api/farming/start` - старт фарма
- `POST /api/farming/stop` - стоп фарма
- `GET /api/stats` - полная статистика
- `WebSocket /ws` - real-time обновления
