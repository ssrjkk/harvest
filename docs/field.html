Метрики публикует скрипт publish_dash.py с машины фермы в ветку gh-pages. Сайт перечитывает state.json раз в минуту (60 с); издатель работает по своему расписанию — по умолчанию каждые 30 минут (планировщик HarvestDashPublish, допустимо 15–60). Если публикации ещё не было — сайт всё равно полностью работает, данные появятся сами.

Кран и диагностика

Проба крана — handshake без траты квоты; запрос — tools/call request_testnet_funds, доливает адрес до максимума сети, повтор безопасен. Без ключа стратегия молча исключается на pre-flight.

Ключ: console.chainstack.com → user/settings/api-keys (env CHAINSTACK_API_KEY, в конфиги не пишется).
