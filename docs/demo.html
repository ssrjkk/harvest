Демо — попробовать без фермы

Два режима: «Новичок» — три шага без терминала, «Про» — конструкторы, генератор, симулятор и справочник. Сайт статический: всё считается в браузере, сервера нет.

Новичок — три шага простыми словами. Про — конструкторы, симулятор и справочник.
1 Сеть 2 Масштаб 3 Запуск

Что будем фармить?

Фарм здесь — учебные транзакции в тестовой сети. Деньги ненастоящие, ничего не стоит.

Какой масштаб?

Smoke: 5 кошельков, 2 круга. Load: 200×5. Soak: 50×20. Chaos: 100×5 без крана — негативный путь.

Кошельки создаются сами. Для первой пробы хватит 5–10.

Один круг — это проход по всем кошелькам: кран, потом транзакции.

Кран — бесплатная раздача тестовых монет. Выключите, только если монеты уже есть.

Всё готово. Осталась одна команда.

  1. Установите Python 3.12 и выполните: pip install -r requirements.txt
  2. Положите скачанный файл-конфиг рядом с auto.py
  3. Вставьте команду в PowerShell и нажмите Enter
  4. Поле сайта оживёт после: python publish_dash.py

Меняет только behavior: паузы, активность, разброс сумм. На команду запуска не влияет.

# нажмите «Сгенерировать YAML»
Готовая команда
python auto.py --wallets 50 --cycles 5
Что произойдёт

Команда пройдёт четыре фазы: добор кошельков → проверка крана и запрос монет → пул фарма с чанками и восстановлением → экспорт CSV/JSON. Повторный запуск продолжит state.json с места обрыва.

Только тестнеты. Ключи считаются в браузере и никуда не отправляются. При первом нажатии «Сгенерировать» страница загрузит ethers с esm.sh — это единственный внешний запрос демо-зоны. Без сети включится честный демо-режим с пометкой.

Конфиг YAML — все поля с границами

Нарушение границ = отказ валидатора и SystemExit(1). Заглушки 0x0 и chain 99999 — не ошибки, а замечания: transfers работают, контрактное пропускается.
