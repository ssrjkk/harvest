Фермер тестнетов,
а не лотерея.

Массовая генерация кошельков, краны, асинхронный фарминг транзакций с «человеческими» профилями поведения, мульти-RPC с EMA-скорингом, веб-портал и Telegram-бот. Живое поле — на странице «Поле», конструкторы и симулятор — в «Демо», справочник — в «Доках».

Живое поле Демо-зона Telegram-бот фермы

Поле читает state.json, который публикует ферма. Остальной сайт полностью статический: ключи из демо-генератора не покидают браузер. Только тестнеты.

02

Что это и что умеет

Один проход пайплайна auto.py — четыре фазы: генерация/переиспользование кошельков → кран → фарм → экспорт. Поведение каждого кошелька детерминировано его адресом, поэтому перезапуск не «палит» ферму сменой паттерна.

Кошельки

Генерация и хранение

BIP-39 через eth_account, импорт/экспорт CSV/JSON, шифрование сид-фраз AES-256-GCM мастер-ключом, дедупликация, защита от CSV-инъекций, атомарная запись файлов.

Кран

Пополнение балансов

Стратегии chainstack / direct / web, pre-flight валидация живых стратегий, retries, rate-limit, прокси-ротация, ensure_balance до target_balance. Нет живых стратегий — включается force_farm.

Фарминг

Асинхронный воркер-пул

Один NetworkManager на сессию, чанки по chunk_size, crash recovery через state.json, динамическое число воркеров по здоровью RPC, адаптивные веса падающих действий.

Анти-сибил

Профили поведения

Активность, паузы, суммы с джиттером, газ, время суток (днём −25%, ночью +150% к пропуску), «отдых» на N циклов, staggered-старт, burst-всплески ×1.6.

RPC

Живучий сетевой слой

Мульти-RPC со списком, EMA-скоринг нод, ротация на лучшую, zombie-воскрешение первым успехом, circuit breaker, адаптивный token-bucket, wait_for_receipt с бюджетом и failover.

Портал

Веб + Telegram

aiohttp-дашборд: метрики, старт/стоп/пауза, история циклов, топ кошельков, экспорт с ключами. Бот на long-polling: те же команды + /doctor, /history, /export. Сессии HMAC, default-deny.

03

Сети и конфиги

Выбор сети — стартовое меню main.py или флаг --config. Пресет «только трансферы» (config.simple.yaml) — для плотного фарма без контрактных адресов: отдельная БД farming_simple.db, gas_limit 21000.

Без ключа они пропускаются адаптивными весами; transfer / claimRewards / stake работают всегда. ABI — в abi/vibevibe.json, контракты верифицированы в Blockscout.

python auto.py --config config.simple.yaml --wallets 200 --cycles 2
04

Запуск за пять минут

Первичная цель проекта — Windows/PowerShell и exe-дистрибутив. Python 3.12.

git clone https://github.com/ssrjkk/harvest.git
cd harvest
pip install -r requirements.txt
python main.py                 # меню: сеть → фарм
python auto.py --doctor        # самодиагностика
Флаги auto.py
FlagЭффект
--wallets NN кошельков (0 — из конфига; по умолчанию 50)
--cycles NN циклов (0 — бесконечно)
--config FILEКонфиг ($FARMER_CONFIG → config.yaml)
--skip-faucet / --skip-farmПропустить кран / фарм
--schedule HПайплайн каждые H часов (мин. 0.05)
--batch / --workers / --fastПачка крана · воркеры · минимальные задержки
--dry-run / --export / --encryptХолостой прогон · экспорт CSV+JSON · AES-шифрование
--history N / --doctor / --versionИстория циклов · диагностика · версия
Сборка exe · портал · тесты · публикация поля
pip install -r requirements.txt
pyinstaller harvest.spec --noconfirm --clean
Unblock-File dist\harvest\harvest.exe

pip install -r requirements-portal.txt
python -m portal                # aiohttp + API + бот

python -m pytest tests -q       # 1467 tests · 57 files

python publish_dash.py          # state.json → gh-pages → поле сайта
Меню main.py

1 — создать кошельки · 2 — один цикл · 3 — live-консоль (p — пауза, q — стоп) · 4 — монитор балансов · 5 — кран на всех · 6 — статистика · 7/8 — экспорт/импорт JSON · C — история · 9 — диагностика RPC · D — doctor · B — бэкапы · G — локальная веб-панель (FastAPI, 127.0.0.1:8080) · L — лицензия · S — смена сети · H — справка. С аргументами main.py делегирует в auto (так же ведёт себя exe).
